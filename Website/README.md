# Supply Chain Website

The main website of the project, the Live Website, is live at: https://supplypulse.de.deplexo.com/ (built by Mohamed Salah).

It presents the same analysis as the Power BI dashboard: Overview, Sales & Profit, Shipping & Cancel Rate, and Predictive pages, with interactive filters and Arabic / English support.

## Simple Page

A simpler, standalone HTML version, the Simple Page, is in the [`Simple Page`](Simple%20Page/) folder. See its [README](Simple%20Page/README.md) for features and how to run it.

A saved browser snapshot of the Live Website is in [`SupplyPulse-snapshot.mhtml`](SupplyPulse-snapshot.mhtml).
