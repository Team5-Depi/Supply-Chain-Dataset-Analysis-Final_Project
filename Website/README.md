# Supply Chain Website

The main website of the project is live at: https://supplypulse.de.deplexo.com/

It presents the same analysis as the Power BI dashboard: Overview, Sales & Profit, Shipping & Cancel Rate, and Predictive pages, with interactive filters and Arabic / English support.

## Simple App

A simpler, standalone version of the web application is in the [`simple app`](simple%20app/) folder. See its [README](simple%20app/README.md) for features and how to run it.
